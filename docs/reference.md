# Анализ референса (upgrader.vip)

Документ фиксирует, что именно было взято из предоставленных архивов сайта
`upgrader.vip` и как это использовано в проекте Upgrader Standoff 2.

> Важно: исходный код референса не копировался. Из архивов извлечены только
> визуальные ориентиры (палитра, типографика, набор анимаций) и структура UX.
> Аналитика (GTM, Яндекс.Метрика), шрифты Google и любые сторонние скрипты
> оригинала в проект не переносились.

## Технологии оригинала

## Анимации

Список ключевых кадров оригинала, воспроизведённых в
`frontend/src/styles/animations.css` собственной реализацией:

- `pulse-glow` — пульсирующее золотое свечение кнопки апгрейда;
- `pulse-yellow` — пульсация рамки выбранного предмета;
- `shimmer` — «бегущий блик» для skeleton-состояний загрузки;
- `win-item-card-scale`, `win-item-image-scale`, `win-color-overlay-fade` — появление выигранного предмета;
- `widget-flash` — вспышка виджета при выигрыше;
- `result-item-image-scale/shake/shimmer` — «оживление» карточки результата;
- `fade-in/out`, `scale-in/out` — модальные окна;
- backdrop модалки: затемнение `#00000080` + `backdrop-filter: blur(8px)`.

## Механика апгрейда в оригинале

Из разбора `main-DBGTFTF5.js`:

1. Пользователь задаёт процент (шаг 5, диапазон 0–100) — от него зависит,
   какие предметы доступны как цель.
2. Стрелка вращается: `rotate(targetValue / 100 * 360deg)`.
3. Фазы анимации подписаны в отладочном выводе оригинала:
   «быстрое вращение» → «замедление» → «статичная».
4. Ставка отправляется на сервер (`performUpgrade()`), ответ содержит уже
   готовый результат (`bet.status`, `winningItem`), после чего вызывается
   `finalizeUpgrade()`.

Это подтверждает архитектуру, заложенную и в нашем ТЗ: **результат считает
сервер, анимация только визуализирует уже полученный ответ**.

В нашей реализации механика усилена: сервер использует provably fair
(HMAC-SHA256 от серверного семени), публикует хеш семени до игры и раскрывает
семя после, поэтому любой результат можно перепроверить вручную.

## Состав интерфейса оригинала

Селекторы компонентов, найденные в бандлах, задали карту нашего UI:

`item-card`, `drop-item`, `my-items-table`, `desired-items-table`,
`odometer` (анимированный баланс), `shop-filters`, `sort-button`,
`payment-modal`, `top-up-dropdown`, `withdrawal-confirm-modal`,
`withdrawal-status`, `transaction-history-modal`, `settings-modal`,
`info-modal`, `notifications-dropdown`, `online` (счётчик онлайна),
`avatar-with-placeholder`, `breadcrumbs`, `carousel`.
