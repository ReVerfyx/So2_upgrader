# Запуск сайта за 10 минут

Пошагово, со ссылками. Ничего писать руками не нужно — только копировать.

> **Сентябрь 2026.** Koyeb перешёл к Mistral AI, и бесплатный тариф Starter
> закрыт для новых аккаунтов. Поэтому основной путь ниже — **Northflank**
> (бесплатный sandbox, сервис не засыпает). Запасной вариант — **Render**
> (карта не нужна, но сервис засыпает после 15 минут простоя).

---

## 1. База данных — Aiven

Ссылка: **https://console.aiven.io/**

1. **Create service** → **PostgreSQL**
2. Провайдер и регион: любой из списка, где доступен бесплатный план
   (обычно `Google Cloud` → `europe-west3 (Frankfurt)`)
3. Тариф: вкладка **Free** → план на 1 ГБ
4. Имя: `stock2-db` → **Create service**
5. Подождать 2–3 минуты, пока статус станет `RUNNING`
6. На странице сервиса → блок **Connection information** → скопировать
   **Service URI** целиком

Выглядит так:

```
postgres://avnadmin:ПАРОЛЬ@pg-xxxxx.c.aivencloud.com:25119/defaultdb?sslmode=require
```

## 2. Приложение — Northflank (основной путь)

Ссылка: **https://app.northflank.com/**

Бесплатный sandbox: 2 сервиса, всегда включены, свой домен и HTTPS.
При регистрации попросят карту для проверки — на sandbox списаний нет.

1. Войти через GitHub
2. **Create new project** → регион `Europe West` → имя `stock2`
3. Внутри проекта: **Create new service** → **Combined service**
   (сборка из репозитория + запуск)
4. **Repository**: `ReVerfyx/So2_upgrader`,
   ветка `claude/upgrader-standoff-2-website-h62wyy`
5. **Build** → тип **Dockerfile**, путь `/Dockerfile`, контекст `/`
6. **Resources** → бесплатный план (`nf-compute-20`, 0.2 vCPU / 512 МБ)
7. **Networking / Ports** → добавить порт `8080`, протокол `HTTP`,
   включить **Publicly expose**
8. **Environment variables** → вставить блок из шага 4
9. **Create service** — первая сборка занимает 3–5 минут

Адрес будет вида `https://web--stock2--<аккаунт>.code.run`.

## 3. Приложение — Render (запасной путь)

Ссылка: **https://dashboard.render.com/**

Карта не нужна. Минус: бесплатный веб-сервис засыпает после 15 минут без
запросов, первый заход после сна ждёт около минуты. Для нашего сайта это
значит, что проверка платежей TON на время сна останавливается и
догоняет пропущенное при следующем заходе на сайт.

1. Войти через GitHub
2. **New** → **Blueprint** → репозиторий `ReVerfyx/So2_upgrader`,
   ветка `claude/upgrader-standoff-2-website-h62wyy`
3. Render прочитает готовый `render.yaml` и создаст сервис
4. Заполнить переменные, помеченные `sync: false` (значения из шага 4)
5. **Apply**

Адрес будет вида `https://stock2.onrender.com`.

## 4. Переменные окружения

Одинаковые для обеих платформ. Заменить значения в угловых скобках:

```env
DATABASE_URL=<SERVICE URI ИЗ AIVEN>
DATABASE_SSL=true
NODE_ENV=production
PORT=8080
SERVE_FRONTEND=true
TRUST_PROXY=1
COOKIE_SECURE=true
SEED_ON_START=true
TEST_MODE=false
SESSION_SECRET=<64 СЛУЧАЙНЫХ СИМВОЛА>
ADMIN_SECRET=<48 СЛУЧАЙНЫХ СИМВОЛОВ>
ADMIN_USERNAME=admin
ADMIN_PASSWORD=<ПАРОЛЬ АДМИНА>
TON_WALLET_ADDRESS=<АДРЕС КОШЕЛЬКА TON>
TON_API_KEY=<КЛЮЧ С TONCENTER.COM>
TON_PROVIDER=toncenter
TON_API_BASE_URL=https://toncenter.com
TON_WATCHER_ENABLED=true
TON_POLL_INTERVAL_MS=30000
RATE_AUTO_UPDATE=true
RATE_REFRESH_MINUTES=15
RATE_SPREAD_PERCENT=3
COIN_MINOR_PER_TON=35000
MIN_DEPOSIT_TON=0.88
DEPOSIT_TTL_MINUTES=30
UPGRADE_HOUSE_EDGE=0.08
APP_URL=https://<АДРЕС САЙТА>
CORS_ORIGINS=https://<АДРЕС САЙТА>
```

Секреты генерируются командами:

```bash
openssl rand -hex 32   # SESSION_SECRET
openssl rand -hex 24   # ADMIN_SECRET
openssl rand -base64 18 | tr -d '/+=' | head -c 20   # ADMIN_PASSWORD
```

Ключ для приёма платежей: **https://t.me/tonapibot** → `/api_key` → mainnet

## 5. После первого запуска

Платформа покажет адрес сайта.

1. Вписать этот адрес в `APP_URL` и `CORS_ORIGINS` → пересобрать сервис
2. Открыть логи сервиса, там должно быть:

```
Миграция применена ... 001_init.sql
Каталог загружен при первом запуске ... создано: 854
Создана учётная запись администратора ... логин: admin
Сервер запущен ... порт: 8080, окружение: production
```

3. Проверить в браузере:

| Адрес | Что должно быть |
| --- | --- |
| `/api/health` | `{"status":"ok","database":"ok"}` |
| `/api/config` | `"testMode":false` |
| `/` | главная страница сайта |

4. Войти администратором → **Админ-панель**:
   * **Коэффициенты** → **Обновить сейчас** — подтянется курс TON с биржи
   * **Пополнения** → **Проверить блокчейн** — проверка связи с toncenter

## 6. Свой домен (по желанию)

Бесплатные варианты и привязка — в [deploy-free.md](deploy-free.md).

Коротко: в настройках сервиса добавить домен → у регистратора создать
`CNAME` на адрес, который покажет платформа → обновить `APP_URL`
и `CORS_ORIGINS` → пересобрать.

---

## 7. Безопасность после запуска

* Сменить пароль базы в Aiven: Service → **Users** → Reset password,
  затем обновить `DATABASE_URL` на платформе
* Пересоздать ключ toncenter, если он где-то засветился
* Добавить `DATABASE_CA_CERT` — сертификат из Aiven (Overview →
  **CA certificate**), чтобы соединение с базой проверялось полностью

---

## Если что-то не поднялось

| Симптом | Причина и решение |
| --- | --- |
| `connect ECONNREFUSED` | Неверный `DATABASE_URL` или база ещё запускается |
| `self signed certificate` | Не задан `DATABASE_SSL=true` |
| Пустой каталог | Не задан `SEED_ON_START=true` |
| `RATE_UNAVAILABLE` при пополнении | Курс не обновился: Админка → Коэффициенты → Обновить сейчас |
| Не входит в аккаунт | `APP_URL` не совпадает с реальным адресом сайта |
| Сборка падает на `COPY` | В настройках сборки не указан контекст `/` |
