# Бесплатный запуск: хостинг и домен

Проект собран в один Docker-образ (бэкенд + фронтенд в одном процессе),
поэтому помещается в бесплатный тариф, где даётся один инстанс.

## Что понадобится

| Компонент | Бесплатное решение | Ограничения |
| --- | --- | --- |
| Приложение | Koyeb или Render | 512 МБ RAM; Render засыпает через 15 мин простоя |
| База данных | **Neon** | 3 ГиБ, не истекает, без карты |
| Домен | поддомен платформы, `is-a.dev`, `eu.org`, DuckDNS | см. ниже |
| HTTPS | даёт платформа | автоматически |

> Бесплатная база **Render живёт 30 дней** и удаляется. Поэтому базу берём
> в Neon, а на Render/Koyeb держим только приложение.

---

## Шаг 1. База данных — Neon

1. Зайдите на <https://neon.com>, войдите через GitHub (карта не нужна).
2. Create project → регион поближе к хостингу приложения (`eu-central-1`).
3. Скопируйте строку подключения вида
   `postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`.

Это значение пойдёт в переменную `DATABASE_URL`.

Бесплатный тариф Neon: 1 проект, 10 веток, 3 ГиБ на ветку, «засыпание»
неактивной базы. Коммерческое использование разрешено.

---

## Шаг 2. Приложение

### Вариант A — Koyeb (не засыпает)

1. <https://www.koyeb.com> → войти через GitHub.
2. **Create Service** → GitHub → выбрать репозиторий и ветку.
3. **Builder: Dockerfile**, путь `./Dockerfile`, порт `8080`.
4. Instance type: **Free**, регион `Frankfurt`.
5. Добавить переменные окружения (см. таблицу ниже).
6. Deploy. Адрес выдадут вида `https://stock2-<аккаунт>.koyeb.app`.

В репозитории есть готовый `koyeb.yaml` — если пользуетесь Koyeb CLI:

```bash
koyeb secret create stock2-database-url --value "postgresql://..."
koyeb secret create stock2-session-secret --value "$(openssl rand -hex 32)"
koyeb secret create stock2-admin-secret --value "$(openssl rand -hex 24)"
koyeb secret create stock2-admin-password --value "ваш-пароль"
koyeb secret create stock2-ton-wallet --value "UQ..."
koyeb secret create stock2-ton-api-key --value "ключ toncenter"
koyeb secret create stock2-app-url --value "https://stock2-аккаунт.koyeb.app"

koyeb service create web --app stock2 --definition koyeb.yaml
```

### Вариант B — Render (проще, но засыпает)

1. <https://render.com> → войти через GitHub.
2. **New → Blueprint** → выбрать репозиторий: Render прочитает `render.yaml`.
3. Заполнить переменные, помеченные как секретные.
4. Create. Адрес будет вида `https://stock2.onrender.com`.

Бесплатный веб-сервис засыпает после 15 минут без запросов; первый запрос
после сна ждёт около минуты. Для площадки с платежами это заметно —
воркер проверки пополнений во сне тоже не работает, и платёж зачислится
только после следующего захода на сайт. Если это критично, берите Koyeb.

### Вариант C — своя бесплатная машина (Oracle Cloud Always Free)

Даёт полноценный сервер (ARM, до 4 ядер и 24 ГБ RAM) без ограничений по сну.
Требует больше настройки: установить Docker и запустить
`docker compose up -d --build` — файл `docker-compose.yml` уже в репозитории.

## Шаг 3. Переменные окружения

Обязательные:

| Переменная | Значение |
| --- | --- |
| `DATABASE_URL` | строка подключения из Neon |
| `DATABASE_SSL` | `true` |
| `SESSION_SECRET` | `openssl rand -hex 32` |
| `ADMIN_SECRET` | `openssl rand -hex 24` |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | учётная запись администратора |
| `APP_URL` | адрес сайта, например `https://stock2.koyeb.app` |
| `CORS_ORIGINS` | тот же адрес |
| `TON_WALLET_ADDRESS` | ваш кошелёк TON |
| `TON_API_KEY` | ключ с toncenter.com |
| `SEED_ON_START` | `true` — при первом запуске создаст каталог и админа |

Остальное имеет разумные значения по умолчанию: `TON_PROVIDER=toncenter`,
`RATE_AUTO_UPDATE=true`, `RATE_SPREAD_PERCENT=3`, `TEST_MODE=false`
(в production отключается принудительно).

После первого запуска в логе будет:

```
Миграция применена ... 001_init.sql
Каталог загружен при первом запуске ... создано: 854
Создана учётная запись администратора ... логин: admin
Сервер запущен ... порт: 8080, окружение: production
```

## Шаг 4. Домен

### Сразу и бесплатно — поддомен платформы

`https://имя.koyeb.app` или `https://имя.onrender.com` с готовым HTTPS.
Этого достаточно, чтобы открыть сайт людям.

### Бесплатные домены и поддомены

| Сервис | Что даёт | Как получить |
| --- | --- | --- |
| **is-a.dev** | `имя.is-a.dev` | Pull request в репозиторий проекта на GitHub, для разработчиков |
| **js.org** | `имя.js.org` | Pull request, для проектов на JavaScript |
| **eu.org** | `имя.eu.org` — не истекает | Заявка на eu.org, модерация от нескольких дней до недель |
| **DuckDNS** | `имя.duckdns.org` | Регистрация через GitHub/Google, выдаётся сразу |
| **Afraid.org (FreeDNS)** | поддомены на чужих доменах | Регистрация, выдаётся сразу |

Домены `.tk`, `.ml`, `.ga`, `.cf` от Freenom больше не выдаются — сервис
фактически прекратил работу, не тратьте на него время.

Платный вариант «почти бесплатно»: домены `.ru` и `.рф` стоят
порядка 200–300 ₽ в год, `.xyz` и `.top` — от 100 ₽ за первый год.
Для площадки с платежами доверия к своему домену заметно больше.

### Привязка своего домена

1. В панели хостинга: Settings → Domains → добавить домен.
2. У регистратора создать `CNAME` на адрес, который покажет платформа.
3. Обновить переменные `APP_URL` и `CORS_ORIGINS`, перезапустить сервис.
4. Если включён вход через Google — добавить новый
   `GOOGLE_REDIRECT_URI` в Google Cloud Console.

HTTPS платформы выпускают сами.

## Шаг 5. Проверка после деплоя

```bash
curl https://ваш-адрес/api/health     # {"status":"ok","database":"ok"}
curl https://ваш-адрес/api/config     # testMode должен быть false
curl -X POST https://ваш-адрес/api/dev/balance   # 404 — тестовых эндпоинтов нет
```

Затем: войти администратором → Админ-панель → Коэффициенты →
**Обновить сейчас** (курс TON подтянется с биржи) и Пополнения →
**Проверить блокчейн** (проверка связи с toncenter).

## О чём стоит знать заранее

**Правила бесплатных хостингов.** Многие площадки в условиях использования
ограничивают или запрещают проекты с азартными механиками и приёмом
платежей. Перед запуском проверьте Terms of Service выбранного хостинга,
иначе сервис могут отключить без предупреждения.

**Правила игры.** Продажа и передача внутриигровых предметов Standoff 2 за
реальные деньги ограничена лицензионным соглашением Axlebolt. Это зона
ответственности владельца площадки — оцените риски до запуска.

**Сон бесплатного тарифа.** На Render во сне не работают фоновые задачи:
проверка пополнений и обновление курса. Платёж зачислится с задержкой —
после первого обращения к сайту. На Koyeb таких пауз нет.

**Резервные копии.** Бесплатные тарифы баз обычно не включают
автоматический бэкап. Настройте выгрузку `pg_dump` по расписанию —
например, отдельным workflow в GitHub Actions.
